# چت روم با جنگو چنلز 

چت روم با جنگو چنلز همون طور که میدونید 
جنگو فقط میتونه درخواست هارو با اچ تی تی پی انجام بده 
برای پروژه های ریل تایم 
باید از جنگو چنلز استفاده کنیم که بتونیم 
ارتباط رو با وب سوکت زنده نگه داریم


#  درباره این پروژه 

این پروژه یک چت روم بین یک نفر و یک نفر هستش 
که شما قابلیت فرستادن پیام و فایل رو دارید 
و همین طور دریافت 
میتونید کاربر مقابل رو بلاک کنید 



# تکنولوژی های استفاده شده 

- django

- daphne

- channels




# روش ران کردن این پروژه 


اول دستور مایگریشن رو باید بزنید برای ساخت دیتابیس 

```bash
python manage.py makemigrations
```
بعد با زدن این دستور جدول های دیتابیس درست بشه 
```bash
 python manage.py migrate
```
در صورت نیاز با این دستور یه سوپر یوزر درست کنید 

```bash
python manage.py createsuperuser

```
  برای ران کردن پروژه با پورت دلخواه خودتون به جای 8080 هر پورتی دوست دارید بزنید

```bash
python manage.py runserver 8080

```

برای ران کردن پروژه 

```bash
python manage.py runserver

```
